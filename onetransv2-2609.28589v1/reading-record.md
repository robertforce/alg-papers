## 问题与已有方法不足

- 三个阶段重复编码用户行为；特征、模型扩展和部署重复建设；训练监督与容量分散。证据 E01。
- 保留级联的理由是阶段候选量与候选特征丰富度不同，尤其精排依赖交叉特征。模型统一不要求消除筛选过程。E01–E03。
- 模型内分享的是候选无关的用户侧历史表示；阶段特征和阶段 token 参数仍异构。共享不等于所有 token 共用全部参数。E02。

## 关键贡献

1. **共享因果用户上下文 + 阶段可见性掩码。** 行为 token 因果关注历史；每个阶段/曝光只读取其请求锚点前缀及同阶段同曝光的前置 token；不读其他阶段或曝光，行为不读阶段 token。前向隔离，反向共同塑造用户表示。E02。
2. **DCGR。** 三层 RQ-KMeans SID，每层码本 8192；四个日志结果维度压到两个前缀位置。三个并行头预测 z_oc、z_disc、z_ad，embedding 相加成 DT_p；依赖消费档位生成 DT_d；再生成三级 SID。E04。
3. **业务偏置。** 决策分布指数倾斜 q∝P exp(βφ)，只改前缀分数，再联合束搜索决策与 SID。CFG 是未来扩展，不是已部署贡献。E05。
4. **模型内蒸馏。** 精排为粗排提供均值中心化、固定温度的 sigmoid 软标签；教师 logit stop-gradient。EMA 均值 0.9999，τ=0.5。E06。
5. **MoE、GQA 与稳定扩展。** token 特定混合参数化；细粒度 SwiGLU 专家、共享专家、sigmoid router；QKNorm、门控注意力、AdamW、μP/Depth-μP。E07。
6. **SNT。** 按用户日窗口共享完整因果编码，各曝光按到达可见性锚定，并在查询—历史键的时间通道用请求相对时间旋转。不是让过去曝光看未来历史。E08。

## 实验与收益归因

### 设置

- 生产日志，非公开基准；曝光时特征快照、固定标签累计窗口，但未给出具体标签窗口长度、样本规模、评估期长度。E09。
- next-batch 时间流式评估，日指标宏平均；排序模型使用相同已曝光样本和标签，没有未曝光候选与采样负例。UAUC 是曝光加权用户 AUC。E09。
- 16 GPU、BF16、每 GPU batch 2048；未公开 GPU 型号、完整结构规格、序列实际长度、专家总数/激活数、真实线上 k/K。E09。
- L_r/L_p/L_f/L_kd 权重 0.1/1/1/1；稀疏 AdaGrad、稠密无一阶动量 AdamW。E06、E09。

### DCGR 证据分层

- E14：主通道 GMV 1.5×（明细 +48.0%），但承担原三通道流量；曝光 +69.3%，GPM −13.0%。这不是系统 GMV +48%。
- E14：发现新类目 4.81 vs 2.15；广告物品 GPM 2.1×。是不同通道原生指标与曝光归因口径，不能相加。
- E15：真实决策 teacher forcing 可提高 HR@1，是信息上界/条件信息实验，不是预测前缀部署精度。
- E15：强制广告 z_ad=1，使广告 HR@1 +31.5%、点击 HR@1 −19.6%，说明解码器确实使用前缀，不证明真实业务结果受因果控制。
- E16：强制最高消费 AOV +38.9%，订单 −33.5%，GMV −7.7%。软偏置强设置的归因 GMV +26.7%；另一个全系统人均口径实验，购买+消费强偏置 GMV +3.0%。两者不是同一分母。
- E17：独立维度串联的顺序存在偏向；但当前并行因子分解是建模假设，不是数据中条件独立性的统计证明。

### 扩展与效率

- E18：门控注意力精排 CTR UAUC +0.15%，MoE +0.30%（计算匹配稠密 FFN）；sigmoid router +0.20%。各柱独立消融，不能相加。
- E19：三次运行下，二阶矩 bias correction 使 CTR UAUC 标准差 0.105%→0.012%；μP 与 Depth-μP 提高扩展收益。三次运行与单个标准差不构成完整显著性检验。
- E20：原始多模态向量在 XS CTR UAUC −0.10%，在 L +0.33%；作者归因于容量足以学习空间映射，属于作者解释而非独立证明。
- E21：SNT 4.4× 训练；序列存储 −95%、非序列存储约减半。
- E21：两阶段 top-k 19.7× 是相对自有未优化实现的延迟约束下最大 batch 吞吐，单请求延迟仅改善 2.3×；再加单步决策 27.6×。不是相对生产系统 27.6×。
- E21：精排未优化 0.58×→融合 1.66×→FP8 2.16×（相对线上精排）；跨级联共享额外 1.53×，作者报告最终 3.2×。分阶段吞吐和全级联吞吐不宜当严格相同分母的乘法等式。

## 工程判断

以下均为 agent_inference，不作为原文结论：

- 缓存应理解为各层可复用历史键值/状态，而非把历史池化成单用户向量；阶段 query 仍读取历史，候选相关 attention 成本并未消失。
- 共享边界的价值在于保持历史与候选解耦；候选相关检索历史、每请求重构历史特征等机制可能破坏复用前提。
- 接入顺序宜先粗精排用户塔共享，再把召回梯度接入，最后引入决策与 SNT，分别评估容量、共享、蒸馏、数据复用与 kernel 收益。
- 用户历史必须按到达时点构建可见性，不能仅按事后事件时间排序；迟到事件回填、可变历史特征、模型版本变更是缓存失效风险。
- stop-gradient 只切断教师输出的该条梯度路径；蒸馏仍可经共享用户骨干间接影响后续教师预测。
- DCGR 的预测决策、结果条件生成与 logit 偏置，不等于强化学习训练或自然语言多步推理。KL 形式相似不构成因果业务收益保证。
- top-k 两阶段的精确性对精确分数比较成立；仍要读原始 logits，减少的是进入后续全局选择的规模和实现开销，不代表移除全部 kV 扫描。

## 局限与未回答问题

1. 完整层数、宽度、参数数、专家数、激活数、序列长度、硬件、延迟、候选 k/K 未公开，无法照文完整复现生产配置。
2. A/B 周期、绝对业务量与统计显著性未报告。9.74% 为全方案收益，不是联合训练或 DCGR 的单组件 GMV 因果效应。
3. 决策档位阈值、无购买时 z_aov 合法组合与标签处理未完整披露。新增维度通常需标签构建与训练适配，不能理解为任何新业务目标都可不训练即插即用。
4. SID 冲突的质量/数量分布、候选去重、跨多个决策路径的同 SID 分数聚合、非法路径过滤细节未报告。
5. 当前排名一致性只基于粗排幸存候选，没有完整证明粗排丢弃集中的精排优质项召回提升。
6. 统计独立性、曝光选择偏差、业务引导越过日志支持域后的风险未由条件生成自动消除。
7. CFG 只是提议；跨周/月 SNT 加速也是未来方向，不能记为已验证收益。
